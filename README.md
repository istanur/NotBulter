# 收租啦 (Notbulter) v1.0

一款面向个人房东的安卓租房管理与记账 App（基于 Capacitor 打包为原生安卓应用）。

## 功能简介
- **多房间管理**：录入各房间的租金、水 / 电底数与单价。
- **自动算账**：按本月水电用量自动计算水费、电费与合计。
- **月度账单**：逐月归档与回看历史账单，支持导出。
- **房东信息**：维护房东联系方式。
- **原生体验**：使用真实系统状态栏；二级页面用手机返回键逐级后退，不会退回桌面。

## 数据存储（重要）
- ✅ 不是浏览器缓存，也不是 `localStorage`；
- ✅ 重启、刷新、升级 App 都不会丢失；
- ✅ 数据仅存于本机，不会上传到任何服务器。

> 只有在安卓「设置 → 应用 → 清除数据」时才会被删除（与所有 App 一致）。
> 网页预览模式下数据仅存于内存、刷新即重置，仅用于演示，不影响已安装的 App。
